# Contributing

## Workflow

1. Branch off `main`: `git switch -c feat/short-description`
2. Make the change, keeping commits focused.
3. Open a pull request describing what changed and why.

## Commit messages

Use the imperative mood in the subject line, under ~72 characters:

```
Add Supabase client initialization
```

## Before opening a PR

- Make sure CI passes.
- Never commit `.env`, API keys, or audio files containing real recordings.
